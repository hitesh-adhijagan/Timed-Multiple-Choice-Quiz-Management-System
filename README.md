# Timed Multiple-Choice Quiz Management System

A web-based timed multiple-choice quiz application built for **CSE326: Internet Programming** using HTML, CSS, and JavaScript.

## Overview
This application provides a structured quiz interface with timed question progression, answer selection, score calculation, and a summary breakdown upon completion.

## Project Structure
- `project.html` – Main structure and layout of the quiz interface and results section
- `style.css` – Styling, layout rules, and visual presentation
- `script.js` – Quiz logic, timer handling, score evaluation, and results rendering

## Features
- Timed multiple-choice quiz flow
- Interactive option selection and quiz navigation
- Results summary with score breakdown and retake option

## How to Run Locally
1. Clone or download the repository to your computer.
2. Open `project.html` in any modern web browser.
